# Validation à la main — HA16 en C25/30, B500

Cas reproduit par `tests/ancrage/ancrage.test.ts` et `tests/ancrage/recouvrement.test.ts`.

## Données

HA16, C25/30, B500, barre droite, a = 60 mm, c₁ = c = 30 mm, σ_sd = f_yd, valeurs
recommandées (γ_C = 1,5, γ_S = 1,15, α_ct = 1).

## Adhérence et longueur de référence

- f_ctm = 0,30 × 25^(2/3) = 2,5650 MPa ; f_ctk,0.05 = 0,7 × 2,5650 = 1,7955 MPa
- f_ctd = 1 × 1,7955 / 1,5 = 1,1970 MPa
- bonnes conditions : f_bd = 2,25 × 1,0 × 1,0 × 1,1970 = **2,6932 MPa**
- f_yd = 500 / 1,15 = 434,78 MPa
- l_b,rqd = 16 / 4 × 434,78 / 2,6932 = **645,75 mm**
- en mauvaises conditions (barre supérieure d'une poutre de 700 mm) : f_bd = 1,8852 MPa,
  l_b,rqd = **922,49 mm**

## Ancrage droit en traction

- c_d = min(a/2 ; c₁ ; c) = 30 mm
- α₂ = 1 − 0,15 × (30 − 16) / 16 = **0,86875**
- sans armature transversale : l_bd = 0,86875 × 645,75 = **560,99 mm**
- avec quatre brins HA8 (ΣA_st = 201,06 mm²), poutre, barre dans l'angle (K = 0,1) :
  λ = (201,06 − 0,25 × 201,06) / 201,06 = 0,75 ; α₃ = 1 − 0,1 × 0,75 = 0,925 ;
  l_bd = 0,86875 × 0,925 × 645,75 = **518,92 mm**
- l_b,min = max(0,3 × 645,75 ; 160 ; 100) = 193,7 mm : ne gouverne pas

## Borne de l'expression (8.5)

c_d = 60 mm, λ = 4, p = 10 MPa : α₂ = α₃ = α₅ = 0,7 (bornés), produit 0,343 < 0,7, **borne activée** :
l_bd = 0,7 × 645,75 = **452,02 mm**.

## Recouvrement, 50 % des barres dans la section

- α₆ = (50 / 25)^0,5 = 1,4142
- avec les quatre brins HA8 : ΣA_st,min = A_s σ_sd / f_yd = 201,06 mm², λ = 0, α₃ = 1
- l₀ = 0,86875 × 1 × 1,4142 × 645,75 = **793,36 mm** ; l₀,min = max(0,3 × 1,4142 × 645,75 ; 240 ; 200) = 274 mm
- α₄ n'intervient pas : le résultat est identique avec des barres transversales soudées.
- φ = 16 mm < 20 mm : aucune armature de couture spécifique (§8.7.4.1(2)).

## Écarts relevés par rapport au plan de développement

Le plan annonçait α₁, α₄ et α₅ « non applicables » en compression. Le tableau 8.2
fixe en compression α₁ = α₂ = α₃ = 1,0, laisse α₄ = 0,7 valable en traction comme en
compression, et ne donne pas de valeur pour α₅ (tiret). C'est ce qui est implémenté.

Le plan situait la zone de mauvaise adhérence des éléments de plus de 600 mm dans le
« quart supérieur » ; la figure 8.2 d) la fixe aux **300 mm supérieurs**. C'est ce qui
est implémenté. À recouper avec le texte en vigueur.
